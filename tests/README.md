# 自动化与边界测试

零依赖的浏览器测试：用 iframe 加载 `index.html?test=1`，通过受控测试接口 `window.__test` 驱动断言（该接口仅在 `?test=1` 时挂载，正常游玩完全不受影响）。

## 运行方式

在仓库根目录启动任意静态服务器后，浏览器打开测试页：

```bash
python3 -m http.server 5173
# 打开 http://127.0.0.1:5173/tests/runner.html
```

页面会逐项输出 ✔/✘ 与明细，并挂载 `window.__TEST_RESULTS`（`{pass,total,okAll,results}`）供外部自动化读取。

## 覆盖项

| 组 | 断言 |
|---|---|
| A 启动 | 无未捕获异常；标题态区块就绪；共享植被几何存在 |
| B 战斗 | `start` 后进入 play；玩家坐标/生命值均为有限数 |
| C 边界 | 极远坐标(±10000)地形高度有限；极端 yaw/pitch 相机无 NaN；260m 流式加载后区块重建且共享几何未被误释放 |
| D 坦克 | 乘坐成功；视点高度=炮塔舱口（±0.8m 容差）；连点只出一发（冷却生效）；1.8s 后可再次开火；车内转视角相机有限；下车无 `vehicleKind`/`flyZ` 残留且不在水中 |
| E 直升机 | 乘坐成功；自动爬升至 ~12m；相机随爬升联动且在座舱内（非旋翼上方）；机炮冷却 0.09s；被摧毁后强制下车、`vehicle` 置空、玩家受溅射伤害 |
| F 收尾 | 全程零控制台错误 |
